# 心屿 · 情绪日记与自我关怀

一个轻量的情绪记录与自我关怀工具，帮你慢慢看懂自己。

## 功能

- **10秒情绪打卡** — 多选情绪标签、强度与精力滑块、场景标记，点几下就能完成记录
- **引导式日记** — 三个可跳过的问题：发生了什么？当时怎么想？现在最需要什么？
- **情绪日历** — 月历视图查看每天的情绪，周/月情绪强度趋势曲线
- **触发因素分析** — 智能发现情绪触发线索，高频触发因素排行榜
- **自我关怀** — 基于B站真实跟练视频：478呼吸法、正念冥想、雨声白噪音、室内快走
- **日记导出** — 一键导出所有记录为txt文件
- **隐私保护** — 所有数据仅保存在本地浏览器

## 使用方法

直接打开 `index.html` 即可使用，无需安装任何依赖。

## 技术栈

- 原生 HTML/CSS/JavaScript
- ECharts（CDN）
- 响应式设计，支持手机和桌面端
